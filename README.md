# Dailo

Dailo is a private, offline-friendly daily task and progress tracker designed for iPhone.

## Features

- Checkbox, percentage, and counter tasks
- Daily progress score
- End-of-day review and carry-forward flow
- History and seven-day insights
- Light and dark themes
- Local backup export and import
- Installable Progressive Web App

## Run locally

Serve the `dist` directory with any static web server. For example:

```sh
npx serve dist
```

## Publish with GitHub Pages

Push the repository to a GitHub repository using the `main` branch. In the repository, open **Settings → Pages** and select **GitHub Actions** as the source. The included workflow publishes the contents of `dist`.

## Install on iPhone

Open the published site in Safari, tap **Share**, choose **Add to Home Screen**, and tap **Add**.
